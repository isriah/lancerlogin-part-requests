# LancerLogin Part Requests plugin v1.4.0

Admins can now choose the name Notion shows as the author of stale-request reminder comments. The new **Name on reminder comments** card is on the **Reminders** tab in **Settings > Modules > Part Requests**, between the settings and the People database. LancerLogin Core stores the name; left blank, comments show Part Requests, as before. Changing it posts nothing to Notion. Requests, Carts, the recipient list and reminders otherwise work exactly as before.

Requires LancerLogin Core `>=2.1.0-beta.13 <3.0.0` (module SDK `^1.9.0`, module contract 1). No database migration and no change to the extension.

## Bugs fixed

None.

## Features added

- The **Name on reminder comments** card on the Reminders tab, built from Core's `NotionCommentNameField`. Admin only, like the rest of the tab.

## Features removed

None.
